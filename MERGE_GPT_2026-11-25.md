## 2. CORRECTION MAJEURE vérifiée live : le sélecteur QuoterV2

**GPT avait raison, notre fix #8 avait tort sur ce point.**

- `0xf7729d43` = keccak de `quoteExactInputSingle(address,address,uint24,uint256,uint160)`
  → c'est le sélecteur du **Quoter V1** (args scalaires, fee AVANT amountIn).
- `0xc6a5026a` = keccak de `quoteExactInputSingle((address,address,uint256,uint24,uint160))`
  → sélecteur du **QuoterV2** (struct).
- Notre code utilisait le sélecteur V1 + l'ordre V1 sur le contrat V2 → revert.
  Le fix #8 avait corrigé l'ordre (struct V2) mais gardé le sélecteur V1 →
  revert persistant → conclusion erronée « single inutilisable sur Base ».

**Vérification live faite pendant ce merge** (eth_call, QuoterV2 Base
`0x3d4e44…`, USDC→WETH, fee 500, 100 USDC, lecture seule) :
- `f7729d43` + struct → `execution reverted`
- **`c6a5026a` + struct → OK : 100 USDC → 0,0594131594328347 WETH**

`v3_quote.py` fusionné utilise désormais `c6a5026a` + pinning de bloc, et
`test_v2.py` exige que le single réponde (et soit à < 0,1 % du path).
Conséquence : la note du fix #8 dans `AUDIT_FIXES_2026-11-25.md`
(« conclusion CONFIRMÉE ») est désormais **invalide** — le single
fonctionne sur Base. Ce fichier historique n'a pas été réécrit ; la
correction est consignée ici.

## 4. ⚠️ ÉCART MAJEUR — la règle « pas de mainnet sans audit + signature »

**La règle de longue date du projet est : simulation/fork only, aucun
mainnet sans audit externe + signature d'Ismail. Le nouveau code NE
l'applique PAS techniquement.**

- `bot.py trade --broadcast` + `arb/live.py submit()` permettent un **vrai
  envoi mainnet** dès qu'un contrat est déployé et qu'une clé est dans
  `CODEMA_PRIVATE_KEY`. Les garde-fous sont réels (re-préparation, budget
  explicite, fraîcheur 2 blocs, nonce, reorg, refus de la clé Anvil,
  une seule soumission, pas de retry) **mais aucun ne vérifie un audit
  externe ni une signature/approbation d'Ismail**.
- Le RUNBOOK l'admet honnêtement : « Le nouveau contrat est testé mais
  **n'a pas subi d'audit externe**. Cette livraison ne prouve pas une
  rentabilité durable et n'a engagé aucun fonds mainnet. »
- `contracts/AtomicArbitrage.sol` est testé (23 tests, dont attaques
  budget d'entrée / partial fill / callbacks non sollicités) mais **non
  audité**. L'ancien contrat `FlashLoanArbitrage.sol` avait la même
  réserve (audit payant obligatoire avant mainnet).
- **Recommandation : ne pas utiliser `trade --broadcast` tant qu'Ismail
  n'a pas explicitement autorisé un envoi mainnet ET qu'un audit externe
  n'a pas eu lieu.** Les commandes `scan` / `watch` / `prepare` /
  `deployment` restent sans envoi. Aucun déploiement mainnet n'a été fait
  pendant ce merge (ni par GPT : remote master = `f2a9d2c`, commit
  `ca951a0` inexistant).

Autres limites notées : watch ~30 s/snapshot sur RPC public (150–158 blocs
de retard) — **ne respecte pas le budget 2 blocs** ; périmètre d'exécution
restreint aux majors Uni/Pancake V3 (pas de memes, pas d'Aerodrome, pas de
Polygon) ; `replay.py` ne fabrique plus de net sans hypothèse gas (le
résumé `replay_analyze.py` n'a pas été adapté — voir §7).

## 8. Points ouverts

1. **Audit externe du contrat `AtomicArbitrage.sol` toujours manquant** —
   condition de la règle mainnet (§4). `trade --broadcast` techniquement
   utilisable sans audit : décision d'Ismail requise avant tout envoi.
2. **Correction du fix #8 à reporter** : `AUDIT_FIXES_2026-11-25.md` affirme
   (à tort) que le single « REVERT TOUJOURS » — désormais infirmé (§2).
   Fichier historique non réécrit ici.
3. **Reproductibilité historique** : 3 runs sur 4 byte-identiques au JSON
   de validation ; 1 run a donné `min_profit_raw` 23134 au lieu de 22986
   (net 0,026054 au lieu de 0,026202, écart 0,6 %) — probable jitter
   d'`eth_estimateGas` sur le premier fork. Sans effet sur le verdict.
4. **`replay_analyze.py`** non adapté au `net_usd=None` de `replay.py`
   (quand `CODEMA_REPLAY_GAS_USD` n'est pas défini) — résumé à vérifier
   avant un prochain replay.
5. **Watch trop lent** : ~30 s/snapshot sur RPC public (150–158 blocs) vs
   budget 2 blocs — une infra plus rapide (RPC privé / WebSocket) reste
   nécessaire pour toute capture en production.
6. `config.yaml` n'est pas requis par le nouveau moteur (`BASE_RPC_URL`
   par défaut = publicnode) — mais l'archive (historique) exige un RPC
   avec archive (Alchemy) ; le défaut public ne suffit pas toujours.
